Security and Responsible Reporting

Security contact information and a transparent overview of QuoteFlow AI website security practices.

Draft for review — see publication requirements on this page.

1. Contact

Report a suspected website or product security issue to info@sparrownexus.in with a description, affected URL/version and safe reproduction steps. Avoid sending personal or confidential customer data.

2. Website safeguards

The public website includes server-side input validation, request-size limits, basic per-IP rate limiting, security headers and server-side email credentials. These safeguards do not constitute a certification or guarantee that the entire product is secure.

3. Responsible reporting

Please avoid accessing, altering or deleting other users’ information, disrupting services or publicly disclosing an unremediated issue. We will need to define a response and acknowledgement process before making any response-time commitment.

4. Scope

This page covers the public website contact process. Security properties of the separate QuoteFlow AI application must be assessed independently; no certification or audit is claimed here.

Publication requirement: confirm the security mailbox, incident response owner, application reporting scope and operational procedures.
